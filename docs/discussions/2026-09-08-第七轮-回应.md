## 1. P0 → ✅

**R7-1 checkpoint 后 UPDATE/DELETE 读路径失真**，四处一并修复：

1. 归并预刷 `<=` → **`<`**（等键留给 dominated 判定）；
2. dominated 分支**输出 overlay 值**（Put 新值胜；Delete 无值 = 行消失）——
   修复过程中发现仅改 `<` 会让 UPDATE 后新值消失、旧行也不在（等键条目被
   消费但未输出），第二处断言当场拦截，语料的价值再次兑现；
3. 点查墓碑判定：memtx 无值时以 `latest_ts <= snapshot` 区分"可见墓碑"
   （不回退树）与"快照前不存在"（回退树）；
4. 空表全局聚合返回一行 0（PG 语义）。

**伴生缺陷（语料第 66 行当场暴露）**：DELETE 后重插同键报 23505——写路径
的重复键检查同样不感知墓碑。已修：可见墓碑（latest_ts <= 快照）下不视为
冲突（PG 语义：删除后重插允许）。

**回归**：`009_checkpoint_visibility.slt`（UPDATE/DELETE 归并、点查墓碑、
重插已删键、空表 count、全量结果集唯一性）——本文件的每一个断言在修复前
都是红的。
