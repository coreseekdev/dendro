# 讨论目录协议

## 文件命名
`YYYY-MM-DD-<主题>-<轮次>.md`（如 `2026-09-07-架构评审-首轮.md`）
回应文件：同名 + `-回应.md` 后缀

## 完成定义（DoD）
每个任务/修复须同时满足：
1. 代码变更（含修复逻辑）
2. 回归测试（证明修复 + 防退化）
3. 文档同步（SPEC / TASK.md / 注释）
