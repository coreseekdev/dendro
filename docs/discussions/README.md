# 讨论目录协议

## 文件命名
`YYYY-MM-DD-<主题>-<轮次>.md`（如 `2026-09-07-架构评审-首轮.md`）
回应文件：同名 + `-回应.md` 后缀

## 完成定义（DoD）
每个任务/修复须同时满足：
1. 代码变更（含修复逻辑）
2. 回归测试（证明修复 + 防退化）
3. 文档同步（SPEC / TASK.md / 注释）

**增补（第十二/十六/十九轮定稿）**：
4. 证据引用一律以 grep 命中为准（杜绝虚构测试名——R13/R17/R19 三次教训）
5. 基线计数以 `scripts/count-tests.sh` 为准（手抄数字四次失准）
6. 代码级批量编辑必须带 assert（replace 静默失败三次的教训）
7. 每个行为修复的回归必须通过**变异自检**——临时禁用新逻辑后测试必须变红（R13-1 空转 / R16-1 Group 空转两次教训）
