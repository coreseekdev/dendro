# 08 里程碑、风险与待决问题

## 1. 里程碑

### v2b —— 标量层（独立可交付，先行）

| 项 | 内容 | 验收 |
|----|------|------|
| B1 | `ScalarStep` 编译器（绑定+折叠+lowering，03 §2）| 编译器单测 R1-R3 |
| B2 | `eval_row` 后端接入 exec（替换 Filter 谓词的 AST 求值路径）| slt 全绿 + 差分（force fallback vs auto）|
| B3 | 两级计划缓存（06；含 schema_version 机制）| 失效矩阵测试（06 §3）逐行过 |
| B4 | EXPLAIN 步列表段 | R4 round-trip |
| B5 | 步列表缓存（1024 上限 + 步数硬断）| S-3 有界测试 |

**不包含**：eval_chunk、Chunk、Source 改造（那是 v2c-1）。
**工作量估计**：编译器+后端 ~600 行核心 + 测试 ~800 行；
schema_version 机制 ~100 行 + 回归。

### v2c-1 —— ChunkPlane 骨架

| 项 | 内容 | 验收 |
|----|------|------|
| C1 | Chunk 类型 + RecordBatch 边界转换器 | round-trip 单测 |
| C2 | 四类 Source（现逻辑搬运，非新逻辑）| 搬运对照 review：逐行 diff 现实现 |
| C3 | 管线协议（push/FlowControl/Ctx 检查）| 单测：Stop 传播/取消/超时 |
| C4 | 派发器 + force_source + EXPLAIN | 派发 micro-bench ≤200ns；差分矩阵 |
| C5 | eval_chunk v1（行循环）| 与 eval_row 对拍 |

**工作量估计**：~1500 行核心 + 差分基建 ~600 行。
**风险最高项**：C2/C4——行为等价的主战场。

归并替换 hash 去重；段增量物化 + 存储字节比 bench。
