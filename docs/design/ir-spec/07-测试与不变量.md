# 07 测试与不变量

> 原则：行为等价迁移的正确性不靠 review 靠对拍；性能不达标不算完成。

## 1. 主护舷：强制派发差分（ADR-5）

```sql
SET dendro.force_source = 'auto' | 'delta' | 'main' | 'main+delta' | 'prolly' | 'fallback';
```

- 每条测试 SQL 以全部可用路径执行，按 §1.1 的**结果等价正式定义**
  比对；
- force_source 仅 debug/测试构建暴露（编译 feature `test-dispatch`，
  release 二进制不含）；
- **矩阵**：语料 × {auto, 每个可用候选}。auto 与每个候选一致 ⇒
  派发器选择不影响正确性。

### 1.1 结果等价正式定义（评审 P1-5：前置交付物，B 阶段之前合入）

现状行序是**路径相关**的（AP 无 overlay 时新段优先序；overlay 非空
经 BTreeMap 重排 pk 序；行路径恒 pk 序；聚合组序首见序）——"逐行全等"
第一天就全红。正式定义：
- **无 ORDER BY 查询**：多重集比较（列名 + 类型标签 + 值；Float 按
  IEEE 位等，累加顺序差 ⇒ 容差 1 ULP 并单列豁免清单；NaN 位等）；
  行序是路径相关现状，v1 **不承诺**跨路径一致；
- **带 ORDER BY（全键）查询**：严格行序比较；
- 该定义文档化在测试 helper（单一定义点），所有差分/对拍共用——
  每处自定义即漂移源。

## 2. 语料（四层，从窄到宽）

1. **手工边界语料**（新增）：NULL 三值逻辑 × {AND, OR, NOT, IN}×
   {有 null/全 null/无 null}；负数字面量（R8 全集）；collation 比较
   （现状=二进制序）；类型提升（Int32/Int64/Float64/Date32 混算）；
   空/矛盾范围（R6 教训）；
2. **slt 全量**：26 文件既有期望不动（行为等价的静态证明）；
3. **ap_tp_differential 扩展**：3 → N 个用例，覆盖 overlay 合并、
   段去重、col_deletes、事务内读（Q-14）× 每条 force_source；
4. **opfuzz/opfuzz-chaos 间接覆盖**：恢复语义不受本 spec 影响，
   全量回归确保无连带破坏。

## 3. 语义回归清单（编译器单测，03 号 spec §8 关联）

| # | 用例族 | 断言 |
|---|--------|------|
| R1 | 负数字面量 IN/范围/比较 | 与行路径同果（R8-6/7 回归迁入）|
| R2 | NULL 三值逻辑编译模式（03 §4）| 真值表全组合对拍现 eval |
| R3 | 常量折叠迁入编译期 | `1+1`、`-(-5)` 折叠同果。**注意**（评审 P0-1）：`NOT NOT x` 不是迁移——optimize.rs 现无 Not 规则，且 Not(Null) 现状报错，新增该规则属语义变更，移出 R3 另列 |
| R4 | 步列表反汇编 | EXPLAIN 输出可再解析（round-trip）|
| R5 | 越界/类型错 | 返回错误不 panic（Kani H1 精神在解释器层）|

## 4. 性能验收（硬线）

| 指标 | 线 | 基准来源 |
|------|----|---------|
| TP 点查吞吐 | **≥ 276k txn/s**（现状 325k 的 85%）| bench plan_cache hit 臂 |
| AP 全表加载 | ≥ 0.69 s（现状 0.771 的 90%）| bench ap_load_rows_s |
| AP 聚合 | ≥ 157 ms（现状 185 的 85%）| bench ap_group_agg_200000_ms |
| 派发器开销 | ≤ 200 ns/查询（纯函数部分单独 micro-bench）| 新增 |

- 任何线不达：**先优化（chunk 池/退化管线/缓存命中），不重开 ADR**；
- bench 进 `benches/results/`，env 指纹照旧。

## 4.5 debug 构建逐算子校验（评审 O7，DuckDB Vector::Verify 同构）

debug 构建下驱动器在每个算子出口校验 Chunk 不变量（len/sel 一致性、
schema 匹配、零行不变量）与 ScalarProgram 跳转边界——在差分红之前
拦住实现 bug，成本低（release 零开销）。

## 5. 不变量映射（与 VERIFICATION.md 账本对齐）

| 账本 | 本 spec 的守卫 |
|------|---------------|
| I-H1（列存/行存一致）| 强制派发差分（§1）——升级为 I-H1 的主检测机制 |
| Q-14（事务可见性）| 规则 2（事务不派 Main）+ 差分含事务内用例 |
| 时间旅行门控（R6 P0）| 候选生成器 version 分支（02 §4）+ 差分含 AS OF 用例 |
| I-C4（段退休界）| 不受影响（CbfSource 只读既有段语义）；回归确保 |
| S-3（资源守卫）| 缓存有界（06）+ 管线内存守卫 + deadline/cancel 每算子检查 |
| R8-6/7（负数字面量）| 编译期折叠单测 R1 |
